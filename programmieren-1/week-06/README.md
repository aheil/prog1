# Week 6: Arrays, References, and First Objects

Session 1 introduces arrays: creating them, indexing, `length`, index-based and for-each loops, and the standard patterns of sum, maximum, counting, searching, and counter arrays. Session 2 uses arrays as the bridge to objects. Students learn that arrays, `Scanner`, and `Random` are objects reached through references; they practise aliasing, `null`, and passing references to methods, and they write a first class of their own (`Point`) with fields only. Instance methods, constructors, and encapsulation follow in weeks 8 and 9.

## Learning goals

By the end of the week, students can declare, create, and fill arrays; process them with index-based and for-each loops without off-by-one errors; implement sum, average, maximum with position, counting, linear search, and counter arrays; and write methods that take and return arrays. They can explain the difference between primitive and reference variables with a memory diagram, predict the effects of aliasing and of passing references to methods, distinguish `==` from comparing contents, avoid `NullPointerException` in arrays of objects, use `Random` with a seed, and define and use a simple class with fields.

## Prerequisites

Loops and loop patterns (weeks 3-4), nested loops and static methods with parameters and return values (week 5).
